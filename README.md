# GUNNAGAN — ガンナガン対戦卓

資料とこのチャットで決めた裁定を元にした、非公式のブラウザ対戦実装です。イラストは使用していません。

- GitHub Pages: https://ginghum.github.io/gun/
- 対戦ルーム・同一版の画面: https://gun-duel-rooms.ginnosukeginno.chatgpt.site/
- CPU戦、4桁の部屋番号による2人対戦、切断後の再接続。
- 銃士12人、技能36種、機銃18丁・専用デッキ360枚を登録。
- 自由編成／候補選出。BLOCK1／BLOCK2／アンリミテッド。

## 遊び方

CPU戦は「CPUと対戦」から編成。対人戦は部屋主が使用範囲と選出方法を選び「部屋を作る」、相手が4桁番号で参加します。技能の選択まで完了すると、双方の開始条件（先後・ライフ・初期手札・機銃配置・銃士効果）を表示します。技能は自分のものだけ表示し、双方の確認後に初期手札を引きます。CPU戦では自分と異なる銃士・機銃を相手が使用します。カードをタップして使用・装填・セットを選びます。装填数とカード枚数は区別されます。COSTとVOLTは選択して支払います。

編成画面はスマートフォンでも最大6候補を同時表示し、選択中の銃士と機銃を横に表示します。ドラフトでは双方の取得済み銃士・機銃と未選択枠を常時表示します。銃士選択の最初から今回の機銃候補9丁も表示し、詳細確認と取得済みの区別ができます。「詳細」で技能や専用デッキを確認できます。「1つ戻る」は編成中だけ有効です。対人戦では相手に手番が移った選択は戻せません。カード一覧は銃士・技能／機銃・専用カードの分類と名前・効果検索に対応します。

「対戦メニュー」の独立した終了欄から、自分・相手の手番を問わずサレンダーできます。通常の射撃・ターン終了ボタンから離し、さらに確認画面を挟んでいます。結果画面には勝敗・決着理由・双方の編成と残りライフを表示し、ログと最終盤面を振り返れます。

メイン操作は取り消せません。相手の射撃・技能に対応する機会がある場合は「対応しない」を選べます。複数枚選択は候補を選んで「この選択で確定」。開始時・終了時・誘発効果の順番も画面で指定します。

対人戦の状態はサーバーに保存されます。同じブラウザの「対人戦に再接続」で再開可能です。保存期間は最終操作から6時間。参加トークンを保存するため、再開するまでブラウザのサイトデータを消さないでください。時間制限はありません。CPU戦は同じ端末のブラウザに自動保存されます。

## 戦闘画面

ロビー、自由編成・候補選出、開始確認、戦闘、決着、一覧、遊び方、ログと詳細を画面内に固定します。手札は左右スワイプ・マウスドラッグ・左右ボタンで横移動できます。長い候補や文章は「前へ／次へ」で読み進め、縦スクロールは使いません。複数枚選択はページをまたいで保持します。カード本文・技能は「詳細」、選択肢は「拡大」、装填内容は「装填詳細」で確認できます。

相手と自分の銃士をそれぞれ中央へ置き、その左右に機銃を配置。ライフ・技能・状態を銃士の下、各ゾーンをその下に並べます。手札・公開カード・使用中カード・支払い候補に所属機銃のアイコンと名前を付けています。伏せ札の所属・名前は公開しません。横向きスマートフォンは盤面が左、手札と操作欄が右です。
銃士12人・機銃18丁に個別のSVGマークを付けています。画像・外部フォントの読み込みはありません。

検証した画面サイズ：390×844、375×667、320×568、844×390、1280×800。ロビー・編成・開始条件・盤面・一覧と詳細・決着を固定画面で確認しています。大きな文字設定では詳細が複数のページに分かれます。

## 開発・検証

Node.js 22以上、外部依存なし。

```sh
npm test
npm run dev
npm run build
```

`src/data.js` がカード定義、`src/engine.js` がルールとCPU、`src/app.js` が画面、`worker/rooms.js` がサーバーです。同じエンジンをCPU戦とサーバーで使います。選択履歴をシードから再現して入力を検証し、各席の非公開情報を取り除いて配信します。クライアントが任意の盤面をサーバーに送る方式ではありません。

`npm run build` で、同じ画面とAPIを含むWorker ESMを `dist/server/index.js` に生成。Sitesへはこのビルドを公開します。GitHubへのpush時は回帰テストを実行します。Pagesは既存の main / root のブランチ公開設定を使用します。

## 検証範囲・制限

- 全カードデータの枚数、全技能・行動・対応の処理登録、代表的な境界裁定、シード付き模擬対戦、通信APIの秘匿・競合・二重送信・再接続を検証。
- CPUは合法手を点数付けする初期方策です。相手の非公開カードは評価に使いません。強さは調整余地があります。
- 全カードの組み合わせを公式原本と照合した実装ではありません。特に多段の無効化、継続効果と誘発が重なる組み合わせには、追加の実戦検証が必要です。
- 対戦履歴が長くなるほど再現処理の負荷が増えます。長時間の連続対戦は負荷検証の対象です。
- 正式なカード画像・ソロ用カード・ランキング・観戦・自動マッチングは含みません。

## 卓上演出

機銃をカードとしてフェルト上に配置し、相手の伏せ手札を扇状に表示。公開行動を1件ずつ、通常約2〜4秒かけて再生します。行動の説明を中央に固定し、ライフ・装填・山札枚数を各行動時点の公開数値へ順に更新します。手札は演出中や相手の選択中も表示し、スライドと詳細確認ができます。ゲームを進める操作は演出後に有効になります。技能は通常発動・対応発動とも、下部の確認欄で「発動を確定」を押してから進みます。山札等の選択待ちは操作欄が青緑に変わります。「一時停止」「次の行動」で手動確認でき、行動名を押すと全文を拡大できます。詳細を読む間は自動再生を止めます。18機銃それぞれに異なる射撃演出、銃士別の技能演出、カードの使用・装填・ドロー・対応・ダメージを表示します。非公開カード名は行動フィードにも含めません。演出はスキップでき、OSの動きを減らす設定にも対応します。動きを減らしても文章の表示時間は短縮しません。

新しい候補選出ではライト・ヘビー・スペシャル各3丁の9丁から選びます。更新前に保存された対戦は当初の6丁で継続します。山札選択にはドロー・装填・ボルテージ等の目的を表示します。

戦闘演出は行動・機能・銃士効果・対応・ダメージ・バーン／ショック・操作制限・ドロー・手札／山札破棄でSVGを区別し、枚数や残りライフを表示します。自動メッセージの待ち時間を短縮し、CPU戦の演出中は盤面・説明文・下部の空白をタップすると次へ進みます。連打直後は450msだけゲーム操作を抑制します。手札やメニュー、詳細画面では先送りしません。

通常の自分の装填は演出待機を省略します。その他の演出中は手札を表示したまま入力をロックします。カードを上方向へドラッグして自分の機銃へ離すと装填でき、銃弾は表裏確認を挟みます。手札の横ドラッグはスクロールです。数値候補が多い場合は直接数値を選び、閃光花火では支払うVとHITを確認できます。対戦履歴は古い順の縦スクロール一画面です。

開始画面のキャッチコピーを削除し、機銃名・手札名・選出候補の文字サイズを調整しました。技能の「支払うボルテージ」には必要枚数だけを仮選択する自動選択ボタンがあります。支払いは確定ボタンまで行いません。射撃・技能・OC・特殊技・HITに大型SVGの光輪・放射線を追加し、盤面テキストより前面に表示します。OSで動きを減らす設定の場合は揺れと動く放射線を抑えます。

手札の装填ボタンは廃止し、装填は機銃へのドラッグで行います。カードの長押しによる標準メニューや文字選択を抑止し、ドラッグ中断時も状態を解除します。スマホの戦闘中候補は2件表示です。対象機銃・山札の選択時は、輪郭が光る盤面の銃本体からも選べます。新規CPU戦では銃士と二丁の補完性に応じて機銃を選び、旧対戦の履歴は従来の選出を再現します。

各機銃の上部に通常装填の残り枠を常時表示します（通常装填禁止は0、無制限は∞）。現在の弾数／最大装填数とは別の表示です。捨て札・ボルテージ・対応・機能と装填詳細は、ページ送りを廃止した縦スクロール一覧です。非公開の相手カードは内容を表示しません。対戦メニューに操作ガイドを追加し、ドラッグ装填・コスト・射撃・ターン終了を説明します。装填できない場合の通知も理由を補足します。

同時発生効果は、同じプレイヤーの同名・同種・同じ対象・同じ数値の効果だけが待機している場合、順番選択を自動処理します。回復などの効果は1件ずつ解決し、途中で異なる誘発が発生した場合は順番を選べます。旧履歴の同一効果の選択も再現できます。

手札のポインターキャプチャ中もタップを明示判定し、ドラッグとカード選択を両立します。選択カード本文は下部で読め、銃弾の表裏確認にも本文を表示します。射撃ボタンの基礎HITは射撃本体と同じ威力表を使い、銃弾・対応前の値として表示します（ロクロは弾数選択）。初回の装填→射撃→Vの案内、おすすめ編成、選出候補の効果要約、CPU選出通知、同じ編成での再戦を追加。自分の通常移動系演出は380ms、重要行動は従来の読める時間を確保します。
