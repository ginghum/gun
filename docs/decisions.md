# この実装で採用するルール

元資料の確定事項を採用し、以下を上書き・補完する。

## 暫定裁定

1. 焔送りへ焔送りは例外的に使用不可。
2. スナイプは重複。
3. チューニング・ボムは同じ射撃に複数枚使用可。1枚ずつ処理し、各処理時のHITで6以上を判定。通常対応とは別。
4. 裏向き機銃は機銃名指定の追加コストに使えない。
5. 技能の対象は相手の対応前に確定する。
6. 白虹貫日は閃光花火のXを指定できず0として扱う。BURSTのV軽減は参照しない。既に必要V以上ある場合は減らさない。
7. ランの技能・亡命少女は資料の更新後の値。
8. すべてをキミには各終了時のライフでBURSTを判定。

## 編成

部屋主が自由編成／候補選出と、BLOCK1／BLOCK2／アンリミテッドを決める。

自由編成では相手との銃士・機銃の重複を認める。自分の2丁は異なる機銃。編成確定後に公開、技能は秘密選択。

候補選出では銃士6人と、ライト・ヘビー・スペシャル各3丁の計9丁を並べる。BLOCK内では銃士6人全員。選出コイントスで①②を決め、銃士①②、機銃①②②①で重複なく取得。技能と左右配置は秘密選択して同時確定する。

対戦の先手は選出順と独立。銃士の速度が高い側、同じなら重量合計が軽い側、それも同じならコイントス。技能選択前に決定する。

## 操作と順序

確定操作の取り消しなし。対応を見送ることができる。任意効果は任意選択。複数の誘発効果はターンプレイヤー側から、同じ側の中では本人が順番を選ぶ。

## 引き分け

両者を合わせて連続5ターン、ライフ変化・ゾーン間移動・装填や技能や機銃の表裏変更・バーンやショック変化がなければ引き分け。進展が一度でもあればカウントを戻す。双方が止められない永久循環も引き分け。

## 表示

イラストなし。文字、マーク、ロゴで判別する。盤面は相手が上、自分が下、手札が最下段。紹介用の余分なセクションを増やさず、対戦操作を中心にする。


## 編成制限と表示（2026-11-23）

- エコとキヨヒメは同じプレイヤーの編成で併用不可。相手が使う分には制限しない。新規対戦・再戦に適用し、既存対戦の履歴再生は保持。
- おすすめ編成はCPU戦専用の選出方法。使用範囲を守り、ライトを最低1丁、相手との銃士・機銃重複なし。
- 候補の「通常装填」は1ターンの通常装填数。最大装填数とは区別する。
- 中央は演出中に現在の演出、演出終了後に現在の入力待ち理由を表示する。相手の選択では非公開の技能やカード名を公開しない。
- 銃士ロゴは公式の公開紹介画像および技能画像から色を解釈した配色であり、公式指定色ではない。原画はゲームへ転載しない。
